本节提供 UPC MCU 关键外设（GPIO、SPI、UART）的完整寄存器参考，包含每个寄存器的基地址、偏移量、位域定义及功能说明。寄存器访问采用"外设基地址 + 偏移量"的统一寻址方式，与 ARM Cortex-M0+ 架构规范一致。裸机开发者可直接通过指针操作寄存器地址，RTOS 驱动开发者则可将本节作为 HAL 层实现的底层依据。所有寄存器宽度均为 32 位，未定义位读出值不确定，写入应置 0。

## 寄存器命名与访问约定

UPC MCU 寄存器的完整地址 = **外设基地址** + **寄存器偏移量**。例如，GPIOA 模式寄存器的地址为：

```c
/* GPIOA_MODER 地址计算示例 */
#define GPIOA_BASE    0x48000000UL
#define GPIO_MODER_OFFSET  0x00UL
#define GPIOA_MODER  (*(volatile uint32_t *)(GPIOA_BASE + GPIO_MODER_OFFSET))

/* 将 GPIOA Pin5 配置为输出模式（位域 [11:10] = 01） */
GPIOA_MODER &= ~(0x3UL << (5 * 2));   /* 先清零 */
GPIOA_MODER |=  (0x1UL << (5 * 2));   /* 写入 01 = 输出模式 */
```

<Note>
  在 C 语言裸机开发中，所有寄存器访问必须使用 `volatile` 关键字修饰指针，以防止编译器优化消除对内存映射寄存器的读写操作。建议使用头文件中预定义的结构体类型（如 `GPIO_TypeDef`）进行访问，以提高可读性和可移植性。
</Note>

## GPIO 外设寄存器

**外设基地址：**
- GPIOA：`0x48000000`
- GPIOB：`0x48000400`
- GPIOC：`0x48000800`

### GPIOx_MODER — 端口模式寄存器

**偏移量：** `0x00` | **复位值：** `0x00000000`（GPIOA 上电默认为 `0xEBFFFFFF`）

每个 GPIO 引脚占用 2 位，共支持 16 个引脚（位 [31:0]，引脚 n 对应位 [2n+1:2n]）：

| 位值 | 模式 | 说明 |
|------|------|------|
| `00` | 输入模式（Input） | 高阻输入，默认模式 |
| `01` | 输出模式（Output） | 通用推挽或开漏输出 |
| `10` | 复用功能模式（Alternate Function） | 引脚由外设（SPI/UART 等）控制 |
| `11` | 模拟模式（Analog） | ADC/DAC 输入输出，禁用数字缓冲区 |

```c
/* 配置示例：PA0 = 模拟输入（ADC），PA5 = 复用功能（SPI SCLK），PA6 = 输出 */
GPIOA->MODER &= ~(0x3 << (0*2) | 0x3 << (5*2) | 0x3 << (6*2));
GPIOA->MODER |=  (0x3 << (0*2))  /* PA0: Analog */
              |  (0x2 << (5*2))  /* PA5: AF */
              |  (0x1 << (6*2)); /* PA6: Output */
```

---

### GPIOx_IDR — 端口输入数据寄存器

**偏移量：** `0x10` | **访问：只读** | **复位值：** `0x00000000`

| 位 | 名称 | 说明 |
|----|------|------|
| [15:0] | IDR[15:0] | 每位对应一个引脚的当前输入电平，1 = 高电平，0 = 低电平 |
| [31:16] | — | 保留，读出值为 0 |

```c
/* 读取 PA3 输入电平 */
uint8_t pa3_level = (GPIOA->IDR >> 3) & 0x1;
```

---

### GPIOx_ODR — 端口输出数据寄存器

**偏移量：** `0x14` | **访问：读/写** | **复位值：** `0x00000000`

| 位 | 名称 | 说明 |
|----|------|------|
| [15:0] | ODR[15:0] | 每位对应一个引脚的输出电平，写 1 输出高，写 0 输出低 |
| [31:16] | — | 保留，写入应置 0 |

<Warning>
  在多任务或中断环境中，对 ODR 的读-改-写（Read-Modify-Write）操作存在竞争风险。建议优先使用原子操作的 BSRR 寄存器进行引脚置位/复位，以避免并发冲突导致的引脚状态错误。
</Warning>

### GPIOx_BSRR — 端口位置位/复位寄存器

**偏移量：** `0x18` | **访问：只写** | **复位值：** `0x00000000`

BSRR 提供对引脚的原子操作，高 16 位执行复位（清零），低 16 位执行置位，两者可同时写入，置位优先级高于复位：

| 位 | 名称 | 说明 |
|----|------|------|
| [15:0] | BS[15:0] | Bit Set：写 1 将对应引脚输出置高，写 0 无效果 |
| [31:16] | BR[15:0] | Bit Reset：写 1 将对应引脚输出置低，写 0 无效果 |

```c
/* 原子操作：将 PA7 置高，PA6 拉低 */
GPIOA->BSRR = (1UL << 7)        /* BS7: PA7 置高 */
            | (1UL << (6 + 16)); /* BR6: PA6 置低 */
```

<Tip>
  BSRR 写操作是单周期原子操作，无需关闭中断即可安全地在中断服务程序（ISR）与主循环中共用。这是 Cortex-M0+ 架构中推荐的 GPIO 操作方式。
</Tip>

## SPI 外设寄存器

**外设基地址：** SPI1 — `0x40013000`

### SPI_CR1 — SPI 控制寄存器 1

**偏移量：** `0x00` | **复位值：** `0x00000000`

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | CPHA | 时钟相位：0 = 第一个边沿采样，1 = 第二个边沿采样 |
| 1 | CPOL | 时钟极性：0 = 空闲低电平（Mode 0/1），1 = 空闲高电平（Mode 2/3） |
| 2 | MSTR | 主从模式：1 = 主机模式，0 = 从机模式 |
| [5:3] | BR[2:0] | 波特率预分频（相对于 fPCLK）：`000`=÷2，`001`=÷4，…，`111`=÷256 |
| 6 | SPE | SPI 使能：1 = 使能 SPI 外设 |
| 7 | LSBFIRST | 帧格式：0 = MSB 先传，1 = LSB 先传 |
| 8 | SSI | 内部从机选择（SSM=1 时有效） |
| 9 | SSM | 软件从机管理：1 = 由软件控制 NSS，0 = 由硬件控制 |
| 11 | DFF | 数据帧格式：0 = 8 位，1 = 16 位 |

```c
/* 配置 SPI1 为主机模式，Mode 0，fPCLK/8，8 位帧，MSB 先传 */
#define SPI1_BASE    0x40013000UL
#define SPI1_CR1  (*(volatile uint32_t *)(SPI1_BASE + 0x00))

SPI1_CR1 = (0x1 << 2)   /* MSTR = 1：主机模式 */
         | (0x2 << 3)   /* BR = 010：fPCLK / 8 */
         | (0x1 << 9)   /* SSM = 1：软件 NSS 管理 */
         | (0x1 << 8)   /* SSI = 1 */
         | (0x0 << 1)   /* CPOL = 0 */
         | (0x0 << 0);  /* CPHA = 0 → SPI Mode 0 */

SPI1_CR1 |= (0x1 << 6); /* SPE = 1：使能 SPI */
```

---

### SPI_SR — SPI 状态寄存器

**偏移量：** `0x08` | **访问：只读（部分位需软件清除）**

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | RXNE | 接收缓冲区非空：1 = RX 数据可读 |
| 1 | TXE | 发送缓冲区空：1 = 可写入新的发送数据 |
| 3 | CRCERR | CRC 校验错误标志（需软件写 0 清除） |
| 4 | MODF | 模式故障（Mode Fault），多主机冲突检测 |
| 5 | OVR | 溢出错误：接收数据未及时读取导致覆盖 |
| 7 | BSY | 忙标志：1 = SPI 正在传输，0 = 空闲 |

```c
/* 完整 SPI 字节收发（轮询方式） */
uint8_t spi_transfer(uint8_t tx_data)
{
    #define SPI1_DR  (*(volatile uint32_t *)(SPI1_BASE + 0x0C))
    #define SPI1_SR  (*(volatile uint32_t *)(SPI1_BASE + 0x08))

    while (!(SPI1_SR & (1 << 1)));  /* 等待 TXE = 1（发送缓冲区空） */
    SPI1_DR = tx_data;
    while (!(SPI1_SR & (1 << 0)));  /* 等待 RXNE = 1（接收完成） */
    return (uint8_t)SPI1_DR;
}
```

<Warning>
  在读取 SPI_DR 之前应确保 RXNE = 1。忽略 RXNE 检查可能导致读取到上次传输的残留数据，产生难以排查的通信错误。高速传输场景下，建议使用 DMA 方式代替轮询，以降低 CPU 占用率并避免 OVR（溢出）错误。
</Warning>

---

### SPI_DR — SPI 数据寄存器

**偏移量：** `0x0C` | **访问：读/写**

- **写操作**：数据加载到发送缓冲区（TX FIFO），触发发送。
- **读操作**：从接收缓冲区（RX FIFO）读取数据，读取后 RXNE 自动清零。

| 位 | 名称 | 说明 |
|----|------|------|
| [7:0] | DR[7:0] | 8 位数据帧模式下的有效数据位 |
| [15:8] | DR[15:8] | 16 位数据帧模式下的高字节（DFF=1 时有效） |
| [31:16] | — | 保留，读出值不确定 |

## UART 外设寄存器

**外设基地址：** USART1 — `0x40013800` | USART2 — `0x40004400`

### USART_CR1 — UART 控制寄存器 1

**偏移量：** `0x00` | **复位值：** `0x00000000`

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | UE | USART 使能：1 = 使能 USART 外设 |
| 2 | RE | 接收使能：1 = 使能接收器 |
| 3 | TE | 发送使能：1 = 使能发送器 |
| 4 | IDLEIE | 空闲线检测中断使能 |
| 5 | RXNEIE | 接收缓冲区非空中断使能 |
| 6 | TCIE | 发送完成中断使能 |
| 7 | TXEIE | 发送缓冲区空中断使能 |
| 10 | PCE | 奇偶校验控制使能 |
| 12 | M | 字长：0 = 8 位数据位，1 = 9 位数据位 |
| 15 | OVER8 | 过采样模式：0 = 16 倍过采样，1 = 8 倍过采样 |

```c
/* 配置 USART1：8-N-1，使能收发，开启 RXNE 中断 */
#define USART1_BASE    0x40013800UL
#define USART1_CR1  (*(volatile uint32_t *)(USART1_BASE + 0x00))

USART1_CR1 = (1 << 3)   /* TE = 1：发送使能 */
           | (1 << 2)   /* RE = 1：接收使能 */
           | (1 << 5)   /* RXNEIE = 1：接收中断使能 */
           | (1 << 0);  /* UE = 1：使能 USART */
```

---

### USART_BRR — 波特率寄存器

**偏移量：** `0x0C` | **复位值：** `0x00000000`

波特率计算公式（16 倍过采样，OVER8 = 0）：

```text
USARTDIV = fCK / 波特率
BRR = round(USARTDIV)

示例：fCK = 48 MHz，目标波特率 = 115200 bps
USARTDIV = 48,000,000 / 115,200 ≈ 416.67
BRR = 0x01A1（十进制 417）
```

| 位 | 名称 | 说明 |
|----|------|------|
| [3:0] | DIV_Fraction | 小数波特率分频值（OVER8=0 时为 4 位） |
| [15:4] | DIV_Mantissa | 整数波特率分频值 |

```c
/* 设置 USART1 波特率为 115200（fCLK = 48 MHz） */
#define USART1_BRR  (*(volatile uint32_t *)(USART1_BASE + 0x0C))
USART1_BRR = 0x01A1; /* 48MHz / 115200 ≈ 417 = 0x1A1 */
```

### USART_ISR — 中断与状态寄存器

**偏移量：** `0x1C` | **访问：只读**

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | PE | 奇偶校验错误 |
| 1 | FE | 帧错误：停止位检测失败 |
| 2 | NF | 噪声检测标志 |
| 3 | ORE | 溢出错误：新数据覆盖未读数据 |
| 4 | IDLE | 空闲线检测 |
| 5 | RXNE | 接收数据寄存器非空：1 = 有数据可读 |
| 6 | TC | 发送完成：移位寄存器与 TDR 均为空 |
| 7 | TXE | 发送数据寄存器空：1 = 可写入新数据 |

```c
/* USART 接收中断服务函数示例 */
void USART1_IRQHandler(void)
{
    #define USART1_ISR  (*(volatile uint32_t *)(USART1_BASE + 0x1C))
    #define USART1_RDR  (*(volatile uint32_t *)(USART1_BASE + 0x28))

    if (USART1_ISR & (1 << 5)) { /* RXNE = 1 */
        uint8_t rx = (uint8_t)USART1_RDR; /* 读取 RDR 自动清除 RXNE */
        rx_buffer_push(rx);
    }
    if (USART1_ISR & (1 << 3)) { /* ORE = 1：溢出错误 */
        /* 写 ICR 寄存器清除 ORE 标志 */
        (*(volatile uint32_t *)(USART1_BASE + 0x20)) |= (1 << 3);
    }
}
```

### USART_TDR / USART_RDR — 发送与接收数据寄存器

**偏移量：** `0x28` | **物理映射：** TDR 与 RDR 共享同一地址

| 操作 | 名称 | 说明 |
|------|------|------|
| 写操作 | TDR | 向发送移位寄存器写入待发送数据（8 位或 9 位） |
| 读操作 | RDR | 从接收移位寄存器读取已接收数据，读取后 RXNE 自动清零 |

<Info>
  TDR 与 RDR 物理上为独立的寄存器，但映射到同一地址（`0x28`）。写操作访问 TDR，读操作访问 RDR，编译器会根据指令类型（`STR`/`LDR`）自动路由到正确的物理寄存器。这与 SPI_DR 的设计原理相同。
</Info>

<Tip>
  在实现 UART 驱动时，建议将 TDR 写入与 ISR 中的 RXNE 处理分离：使用 TXEIE 中断驱动发送（零等待 DMA 风格），使用 RXNEIE 中断驱动接收，并配合环形缓冲区（ring buffer）管理收发数据，可有效避免在高波特率下出现数据丢失。
</Tip>
