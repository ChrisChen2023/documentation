本页提供昕原半导体 ATOM-01 存算一体 SoC 及 ATOM-EVB 评估板的完整硬件规格参数。ATOM-01 是面向量产集成的裸芯，工程师可直接将其焊接到自定义产品 PCB；ATOM-EVB 评估板则为原型开发与算法验证阶段提供开箱即用的完整硬件平台，两者在电气和软件层面完全兼容，评估阶段积累的模型与代码可无缝迁移至量产设计。

## ATOM-01 SoC 芯片规格

ATOM-01 采用 55nm 标准 CMOS 工艺，将 eReRAM CIM 阵列、数字控制逻辑、SRAM 缓冲区及多种外围接口集成于单颗芯片，兼顾极致能效与工程可用性。

| 参数 | 规格值 |
|---|---|
| **工艺节点** | 55nm CMOS（嵌入式 eReRAM 工艺） |
| **CIM 阵列规模** | 16 × (256×256) 1T1R 存算阵列 |
| **峰值算力（INT4）** | 16 TOPS |
| **峰值算力（INT8）** | 8 TOPS |
| **片上 SRAM** | 2MB（激活值缓冲 / 中间特征图） |
| **片上 eReRAM** | 8MB（模型权重非易失存储） |
| **主机接口** | PCIe Gen3 ×4 / USB 3.0 |
| **辅助接口** | UART × 2, SPI × 2, I²C × 2, GPIO × 16 |
| **核心供电** | 1.0V |
| **IO 供电** | 1.8V / 3.3V（可配） |
| **模拟供电** | 2.5V（CIM 阵列读写电路） |
| **典型推理功耗** | 500mW @ 8 TOPS（INT8 满载） |
| **静态待机功耗** | < 5mW |
| **工作温度范围** | −20°C ~ +85°C |
| **封装形式** | FCLBGA-256，10×10mm，0.65mm Ball Pitch |

<Note>
  eReRAM 权重存储为非易失性存储器，掉电后权重数据不丢失，无需上电重新加载模型，适合低功耗唤醒推理场景。权重编程（模型部署）通过 PCIe/USB 接口由主机执行，单次部署耗时约 200ms（8MB 满载）。
</Note>

### CIM 阵列架构说明

ATOM-01 内部共有 16 组独立 CIM 阵列，每组包含 256×256 个 1T1R（一晶体管一阻变器）存储单元。阵列采用分时复用调度策略，支持跨层流水线执行。关键架构参数如下：

| 架构参数 | 数值 |
|---|---|
| 单阵列规模 | 256 × 256 单元 |
| 阵列总数 | 16 |
| 存储精度 | 2-bit/cell（MLC） |
| MVM 并行度 | 256路并行 |
| ADC 分辨率 | 8-bit SAR ADC（每列） |
| 数字后处理 | 量化截断、ReLU、BN 融合 |

<Warning>
  模拟供电（2.5V）对噪声敏感，PCB 设计时须为 VDDA 管脚配备独立 LDO 稳压及足量去耦电容（建议每管脚 100nF + 10μF 组合），并与数字供电区域保持充分的布局隔离。详见《ATOM-01 硬件设计指南》（文档编号 HW-DG-001）。
</Warning>

## ATOM-EVB 评估板规格

ATOM-EVB 是以 ATOM-01 为核心的完整评估平台，板载主机 MCU、内存、存储及丰富外设接口，支持独立运行 Linux 操作系统，无需外接主机即可完成模型部署与推理验证。

| 参数 | 规格值 |
|---|---|
| **PCB 尺寸** | 100 × 80mm，4 层板 |
| **AI 加速芯片** | ATOM-01（见上节规格） |
| **主机 MCU** | 昕原 UPC03（Arm Cortex-M33 @ 200MHz） |
| **系统内存** | 1GB LPDDR4（800MHz） |
| **板载存储** | 16GB eMMC 5.1 |
| **USB 接口** | USB-C × 1（5V/3A 供电 + USB 3.0 数据） |
| **摄像头接口** | MIPI CSI-2 × 1（4-lane，最高 4K@30fps） |
| **网络接口** | 100M Ethernet（RJ45，via RTL8211） |
| **扩展接口** | 40-pin GPIO Header（兼容树莓派布局） |
| **调试接口** | Micro USB（UART 串口调试，CH340） |
| **主供电方案** | USB-C 5V/3A |
| **备选供电方案** | DC 插座 12V/2A（5.5/2.1mm） |
| **操作系统** | Linux 5.15 LTS（Yocto Project 构建） |
| **预编译镜像** | 提供，含 ATOM SDK 运行时与 Demo 程序 |
| **工作温度** | 0°C ~ +70°C |

```
              100mm × 80mm
```

### 预编译镜像内容

ATOM-EVB 配套的 Linux 镜像基于 Yocto Project 构建，预装以下组件：

| 组件 | 版本 | 说明 |
|---|---|---|
| Linux Kernel | 5.15 LTS | 含 ATOM-01 内核驱动 |
| atomrt 运行时 | 1.2.0 | C/Python 推理运行时 |
| atom-sdk | 1.2.0 | Python SDK 及工具链 |
| atom-cli | 1.2.0 | 命令行管理工具 |
| Demo 模型库 | — | ResNet-18、MobileNetV2、DS-CNN 等 |
| OpenCV | 4.8.0 | 图像预处理支持 |
| Python | 3.10 | 含 NumPy、Pillow |

<Tip>
  ATOM-EVB 的 40-pin GPIO Header 与树莓派 4B 引脚定义兼容，可直接接入树莓派生态的摄像头模块、传感器扩展板等外设，方便快速搭建多传感器推理原型。
</Tip>
