`atomrt` 是 ATOM 存算一体方案的推理运行时库，运行于 ATOM-EVB 板载 Linux 系统之上，直接对接 ATOM-01 内核驱动。`atomrt` 同时提供面向嵌入式集成的 **C API** 与面向快速原型开发的 **Python API**，两者在功能上完全对等。C API 适合对延迟和资源占用有严苛要求的量产嵌入式应用；Python API 适合算法工程师进行模型验证、性能分析与快速集成开发。本文档详细描述两套 API 的函数/方法签名、参数说明、返回值、错误码及使用示例。

## 运行时架构概览

```
应用层代码  (C Application / Python Script)
         │
    ┌────┴────────────────────┐
    │   atomrt 运行时 API      │  ← 本文档描述的接口层
    │  (libatomrt.so / .a)    │
    └────────────────────────┘
         │
    ┌────┴───────────────────┐
    │  ATOM-01 内核驱动       │  /dev/atom0
    │  (atom_drv.ko)         │
    └────────────────────────┘
         │
    ┌────┴───────────────────┐
    │  ATOM-01 硬件           │  CIM 阵列 / eReRAM
    └────────────────────────┘
```

## C API 参考

C API 头文件路径：`/usr/include/atom/atom_runtime.h`。编译时链接 `-latomrt`。

### 数据类型定义

```c
/* 推理上下文句柄（不透明指针） */
typedef struct atom_context   atom_context_t;

/* 模型句柄（不透明指针） */
typedef struct atom_model     atom_model_t;

/* 张量描述符 */
typedef struct {
    void*    data;        /* 数据指针（调用方负责分配与释放） */
    int      ndim;        /* 维度数量 */
    int      shape[8];    /* 各维度大小，NCHW 顺序 */
    int      dtype;       /* ATOM_DTYPE_FLOAT32 或 ATOM_DTYPE_INT8 */
    size_t   nbytes;      /* 数据总字节数 */
} atom_tensor_t;

/* 数据类型常量 */
#define ATOM_DTYPE_FLOAT32  0
#define ATOM_DTYPE_INT8     1
```

### 错误码

| 错误码 | 数值 | 含义 |
|---|---|---|
| `ATOM_OK` | `0` | 操作成功 |
| `ATOM_ERR_DEVICE` | `-1` | 设备未找到或驱动未加载（检查 `/dev/atom0`） |
| `ATOM_ERR_MODEL` | `-2` | 模型文件格式错误或版本不兼容 |
| `ATOM_ERR_SHAPE` | `-3` | 输入张量形状与模型不匹配 |
| `ATOM_ERR_MEM` | `-4` | 内存或 eReRAM 分配失败 |

### `atom_create_context`

创建 ATOM 推理上下文，并与指定设备节点建立连接。同一进程内可创建多个上下文对应多个设备，但 ATOM-EVB 通常只有一个设备节点 `/dev/atom0`。

```c
atom_context_t* atom_create_context(const char* device);
```

| 参数 | 类型 | 说明 |
|---|---|---|
| `device` | `const char*` | 设备节点路径，如 `"/dev/atom0"` |

**返回值：** 成功返回非空上下文指针；失败返回 `NULL`（设备不存在或权限不足，检查 `errno`）。

### `atom_load_model`

从 `.atom` 文件加载模型，将权重编程至 ATOM-01 片上 eReRAM。此操作为阻塞调用，典型耗时 150–300ms（取决于模型大小）。

```c
atom_model_t* atom_load_model(atom_context_t* ctx, const char* model_path);
```

| 参数 | 类型 | 说明 |
|---|---|---|
| `ctx` | `atom_context_t*` | `atom_create_context` 返回的上下文指针 |
| `model_path` | `const char*` | `.atom` 模型文件的文件系统路径 |

**返回值：** 成功返回非空模型句柄；失败返回 `NULL`，错误原因通过 `atom_last_error()` 获取。

### `atom_run_inference`

执行单次推理。输入张量数据由调用方提供，输出张量内存由调用方预分配，运行时将结果写入 `output->data`。

```c
int atom_run_inference(atom_model_t*   model,
                       atom_tensor_t*  input,
                       atom_tensor_t*  output);
```

| 参数 | 类型 | 说明 |
|---|---|---|
| `model` | `atom_model_t*` | `atom_load_model` 返回的模型句柄 |
| `input` | `atom_tensor_t*` | 输入张量（NCHW，float32 或 int8） |
| `output` | `atom_tensor_t*` | 输出张量（调用方预分配 `data` 缓冲区） |

**返回值：** `ATOM_OK (0)` 表示成功；负数错误码表示失败（见错误码表）。

### `atom_destroy_model`

释放模型占用的 eReRAM 资源及内核侧分配的内存。加载同一 eReRAM 的新模型前必须先调用此函数。

```c
void atom_destroy_model(atom_model_t* model);
```

### `atom_destroy_context`

释放推理上下文，关闭与设备的连接。程序退出前必须调用，否则设备节点可能维持占用状态。

```c
void atom_destroy_context(atom_context_t* ctx);
```

### 完整 C API 使用示例

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "atom/atom_runtime.h"

int main(void)
{
    /* 1. 创建推理上下文 */
    atom_context_t* ctx = atom_create_context("/dev/atom0");
    if (!ctx) {
        fprintf(stderr, "错误：无法打开 ATOM 设备，请检查驱动是否加载\n");
        return 1;
    }

    /* 2. 加载模型（权重写入 eReRAM，约 200ms） */
    atom_model_t* model = atom_load_model(ctx, "/opt/models/mobilenetv2.atom");
    if (!model) {
        fprintf(stderr, "错误：模型加载失败，错误码 %d\n", atom_last_error());
        atom_destroy_context(ctx);
        return 1;
    }

    /* 3. 准备输入张量（NCHW float32，224×224×3） */
    int    input_size = 1 * 3 * 224 * 224;
    float* input_buf  = (float*)malloc(input_size * sizeof(float));
    /* ... 填充输入数据（图像预处理后的归一化浮点数组）... */

    atom_tensor_t input = {
        .data   = input_buf,
        .ndim   = 4,
        .shape  = {1, 3, 224, 224},
        .dtype  = ATOM_DTYPE_FLOAT32,
        .nbytes = input_size * sizeof(float)
    };

    /* 4. 准备输出张量（1000 类 logits） */
    float* output_buf = (float*)malloc(1000 * sizeof(float));
    atom_tensor_t output = {
        .data   = output_buf,
        .ndim   = 2,
        .shape  = {1, 1000},
        .dtype  = ATOM_DTYPE_FLOAT32,
        .nbytes = 1000 * sizeof(float)
    };

    /* 5. 执行推理 */
    int ret = atom_run_inference(model, &input, &output);
    if (ret != ATOM_OK) {
        fprintf(stderr, "推理失败，错误码：%d\n", ret);
    } else {
        /* 找 Top-1 */
        int   top1_idx  = 0;
        float top1_conf = output_buf[0];
        for (int i = 1; i < 1000; i++) {
            if (output_buf[i] > top1_conf) {
                top1_conf = output_buf[i];
                top1_idx  = i;
            }
        }
        printf("Top-1 类别索引：%d，置信度：%.4f\n", top1_idx, top1_conf);
    }

    /* 6. 资源释放 */
    free(input_buf);
    free(output_buf);
    atom_destroy_model(model);
    atom_destroy_context(ctx);
    return 0;
}
```

编译命令：

```bash
gcc -O2 -o infer_demo infer_demo.c \
    -I/usr/include/atom \
    -latomrt \
    -o infer_demo
```

## Python API 参考

Python API 通过 `atom_sdk` 包提供，安装后直接导入使用。

### `Runtime` 类

```python
from atom_sdk import Runtime
```

#### `Runtime(device='atom0')`

初始化运行时实例并连接指定 ATOM 设备。

```python
rt = Runtime(device='atom0')
```

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `device` | `str` | `'atom0'` | 设备名称（对应 `/dev/atom0`）或远程地址（`'192.168.1.100:7788'`） |

#### `rt.load(model_path)`

加载 `.atom` 模型文件，返回 `AtomModel` 实例。

```python
model = rt.load('model.atom')
```

#### `AtomModel.infer(input_array)`

执行单次推理，返回 NumPy 数组格式的输出结果。

```python
import numpy as np

# 输入为 NumPy 数组，形状须与模型输入匹配
input_arr = np.random.randn(1, 3, 224, 224).astype(np.float32)
output = model.infer(input_arr)   # 返回 np.ndarray，形状 [1, 1000]
```

| 参数 | 类型 | 说明 |
|---|---|---|
| `input_array` | `np.ndarray` | 输入数组，dtype 为 `float32` 或 `int8`，形状为 NCHW |

**返回值：** `np.ndarray`，dtype 为 `float32`。

#### `AtomModel.benchmark(input_array, iterations=100)`

对模型执行多次推理并统计性能指标，返回字典格式的统计结果。

```python
stats = model.benchmark(input_array, iterations=100)
print(stats)
```

返回字典示例：

```python
{
    'iterations':     100,
    'avg_latency_ms': 2.13,
    'min_latency_ms': 2.09,
    'max_latency_ms': 2.41,
    'p99_latency_ms': 2.38,
    'throughput_fps': 468.7,
    'avg_power_mw':   512.0,
    'energy_uj':      1090.2
}
```

### 完整 Python API 使用示例

```python
import numpy as np
from PIL import Image
from atom_sdk import Runtime

# 1. 初始化运行时
rt = Runtime(device='atom0')

# 2. 加载模型
model = rt.load('/opt/models/resnet18.atom')
print(f"模型已加载，eReRAM 占用：{model.ereeram_usage_kb} KB")

# 3. 图像预处理（ImageNet 标准化）
img = Image.open('test.jpg').resize((224, 224))
x   = np.array(img, dtype=np.float32) / 255.0
mean = np.array([0.485, 0.456, 0.406])
std  = np.array([0.229, 0.224, 0.225])
x = (x - mean) / std
x = x.transpose(2, 0, 1)          # HWC → CHW
x = np.expand_dims(x, axis=0)     # 添加 Batch 维度 → NCHW

# 4. 执行推理
output = model.infer(x)            # shape: [1, 1000]
top5_idx  = np.argsort(output[0])[::-1][:5]
top5_conf = output[0][top5_idx]

print("Top-5 预测结果：")
for idx, conf in zip(top5_idx, top5_conf):
    print(f"  类别 {idx:4d}: {conf:.4f}")

# 5. 基准测试
stats = model.benchmark(x, iterations=500)
print(f"\n性能基准（500 次推理均值）：")
print(f"  平均延迟：{stats['avg_latency_ms']:.2f} ms")
print(f"  吞吐率：  {stats['throughput_fps']:.1f} FPS")
print(f"  平均功耗：{stats['avg_power_mw']:.0f} mW")
print(f"  推理能耗：{stats['energy_uj']:.1f} μJ")
```

## 输入/输出张量格式

| 属性 | 要求 |
|---|---|
| **内存布局** | NCHW（批次×通道×高×宽） |
| **Batch Size** | 当前版本固定为 1（不支持批量推理） |
| **输入 dtype** | `float32` 或 `int8`（取决于模型量化方式） |
| **输出 dtype** | 统一为 `float32`（运行时自动反量化） |
| **数值范围（float32 输入）** | 须与训练时预处理一致（通常为均值/方差归一化后的值） |

<Note>
  当前 atomrt 1.2.0 版本固定 Batch Size = 1。批量推理将在 atomrt 1.3.0 中引入，届时 `atom_run_inference_batch()` 接口将随 SDK 更新提供。
</Note>

## 多模型并发推理

ATOM-01 的 16 个 CIM 阵列相互独立，支持同时加载多个模型并分别执行推理（各模型权重分区占用不同的 eReRAM 区域，总占用不得超过 8MB）。

```python
from atom_sdk import Runtime
import numpy as np

rt = Runtime(device='atom0')

# 加载两个模型（总 eReRAM 占用须 ≤ 8MB）
classifier = rt.load('/opt/models/mobilenetv2.atom')   # 1.8MB
detector   = rt.load('/opt/models/yolov5s.atom')       # 3.5MB

print(f"总 eReRAM 占用：{rt.ereeram_used_kb} KB / 8192 KB")

# 各模型独立执行推理，互不干扰
frame = np.random.randn(1, 3, 224, 224).astype(np.float32)

cls_result = classifier.infer(frame)
det_result = detector.infer(frame)

print("分类结果 shape：", cls_result.shape)   # [1, 1000]
print("检测结果 shape：", det_result.shape)   # [1, 25200, 85]（YOLOv5s）
```

<Warning>
  多模型并发加载时，各模型的 eReRAM 总占用量不得超过 8MB。加载前请通过 `atom-compiler analyze` 确认每个模型的存储需求，或通过 `rt.ereeram_used_kb` 查询当前剩余容量。超出容量时 `rt.load()` 将抛出 `AtomMemError` 异常。
</Warning>

<Tip>
  使用多模型并发推理时，建议采用 Python `threading` 为每个模型分配独立线程以充分利用 CIM 阵列并行性。`atomrt` 运行时内部已对多线程访问做了线程安全保护，无需在应用层加锁。
</Tip>
