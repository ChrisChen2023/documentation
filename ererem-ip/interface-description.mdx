昕原半导体 eReRAM IP 采用业界标准 AMBA（Advanced Microcontroller Bus Architecture）总线接口，默认提供 APB（Advanced Peripheral Bus）版本，可选 AHB（Advanced High-performance Bus）版本。APB 接口适用于低功耗、低频率的外设挂载场景，而 AHB 接口则适合对带宽有更高要求的高速访问应用。两种接口版本共享相同的存储阵列核心，仅总线控制层逻辑有所差异，集成工程师可根据系统总线架构灵活选择。

## AMBA APB 与 AHB 接口概述

eReRAM IP 的 APB 接口遵循 AMBA 3 APB 协议规范，支持最高 100MHz 操作频率，单次读操作延迟可配置为 1 或 2 个等待周期（Wait State），写操作通过 `PREADY` 信号动态指示完成状态。AHB 接口版本遵循 AMBA 2 AHB 协议规范，支持突发传输（Burst Transfer），最高操作频率为 200MHz。

本文以 **APB 接口**为主进行信号说明。如需获取 AHB 接口完整信号定义，请参阅交付包中的 AHB Datasheet 附录。

## 接口信号列表

下表列出 eReRAM IP APB 版本的全部接口信号，包含电源引脚（Power Pin）定义：

| 信号名称 | 方向 | 位宽 | 描述 |
|---|---|---|---|
| `PCLK` | Input | 1 | APB 时钟信号，所有 APB 总线传输均在 PCLK 上升沿同步采样 |
| `PRESETn` | Input | 1 | 系统复位信号，低电平有效；复位后所有内部寄存器恢复初始状态 |
| `PSEL` | Input | 1 | 片选信号，由总线互联（Bus Interconnect）驱动，高电平表示本 IP 被选中 |
| `PENABLE` | Input | 1 | 使能信号，在 APB 传输的第二个周期（Access Phase）拉高，表示传输进入使能阶段 |
| `PWRITE` | Input | 1 | 写使能信号；高电平为写操作，低电平为读操作 |
| `PADDR` | Input | 12 | 地址总线，对应字节地址，寻址范围为 4KB（`0x000`～`0xFFF`）|
| `PWDATA` | Input | 32 | 写数据总线，在写操作的 Access Phase 保持有效 |
| `PRDATA` | Output | 32 | 读数据总线，在读操作完成后（`PREADY` 拉高时）输出有效数据 |
| `PREADY` | Output | 1 | 就绪信号，高电平表示当前操作已完成；低电平时总线主机须插入等待周期 |
| `PSLVERR` | Output | 1 | 从机错误标志，高电平表示发生总线错误（如地址越界或操作违规）|
| `VDD` | Power | 1 | 核心电源，标称电压 1.8V，供数字逻辑及存储阵列控制电路使用 |
| `VDDIO` | Power | 1 | IO 电源，标称电压 3.3V，供 IO 缓冲器及 APB 接口电平转换电路使用 |
| `VSS` | Power | 1 | 地（GND），所有电路的参考地电位 |
| `VPP` | Power | 1 | 编程高压引脚，由宏单元内部倍压电路（Charge Pump）自动产生（典型值 5V），**禁止从芯片外部向此引脚施加电压** |

<Warning>
  `VPP` 引脚由 eReRAM 内部倍压电路驱动，其电压幅度超出标准 IO 耐压范围。在布局规划阶段请确保该引脚不与外部 PAD 直连；在 ESD 设计规则检查（ESD DRC）中，应将 `VPP` 网络设置为豁免（Exempt）或使用昕原提供的定制 ESD 规则文件。
</Warning>

## 读操作时序

APB 读操作遵循标准 APB 两阶段协议，在存储阵列读取延迟较大时，IP 内部会通过拉低 `PREADY` 信号插入等待周期。

**读操作时序步骤：**

1. **Setup Phase（T1）**：总线主机在 `PCLK` 上升沿前建立 `PSEL=1`、`PENABLE=0`、`PWRITE=0`，同时将目标地址驱动到 `PADDR`。
2. **Access Phase（T2）**：`PCLK` 上升沿后，`PENABLE` 拉高，IP 开始内部读取操作。若 eReRAM 存储阵列未准备好，`PREADY` 保持低电平，总线处于等待状态。
3. **数据有效（T2 或 T2+n）**：当内部读操作完成，IP 拉高 `PREADY`，`PRDATA` 上的数据同步有效，总线主机在该时钟沿采样读数据。

```
PCLK     ___/‾‾‾\___/‾‾‾\___/‾‾‾\___/‾‾‾\
PSEL     ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\
PENABLE  ____________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\
PWRITE   ______________________________________（保持低电平）
PADDR    --------< ADDR >------------------
PREADY   ________/‾‾‾\___/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\  （第一个 Access Phase 插入 1 个等待周期）
PRDATA   ---------------------------< DATA >
```

<Note>
  eReRAM 读操作典型延迟为 &lt;10ns（TT/1.8V/25°C），在 100MHz APB 时钟下通常无需插入等待周期。在 SS/1.62V/125°C 最坏角下，建议配置至少 1 个等待周期，具体数值请参阅《eReRAM IP 时序约束与 SDC 配置指南》。
</Note>

## 写操作时序

APB 写操作同样遵循两阶段协议。由于 eReRAM 单次编程（Program）操作涉及电阻态切换，写周期时间（tWR）远长于读操作，IP 将在编程完成前持续拉低 `PREADY`。

**写操作时序步骤：**

1. **Setup Phase（T1）**：总线主机建立 `PSEL=1`、`PENABLE=0`、`PWRITE=1`，驱动 `PADDR` 与 `PWDATA`。
2. **Access Phase（T2 开始）**：`PENABLE` 拉高，IP 锁存地址与写数据，启动内部编程状态机（Program FSM）。`PREADY` 保持低电平直至编程完成（最长约 10μs）。
3. **写操作完成**：编程状态机完成后，`PREADY` 拉高，总线主机可在下一周期发起新的传输。若发生写错误，`PSLVERR` 将同步拉高一个周期。

<Warning>
  在 `PREADY` 拉高之前，总线主机**不得改变** `PADDR`、`PWDATA` 或 `PWRITE` 的值，否则可能导致存储单元写入数据错误或写操作中断，造成不可恢复的数据损坏。
</Warning>

## APB 寄存器读写 Verilog 示例

以下代码展示了 SoC 软件侧驱动 APB 主机控制器，对 eReRAM IP 执行寄存器读写操作的典型 Verilog 行为模型示例，可用于仿真验证或驱动开发参考。

<CodeGroup>

```verilog APB 写操作（Task）
// APB 写操作 Task —— 向 eReRAM 指定地址写入 32-bit 数据
task apb_write;
  input [11:0] addr;
  input [31:0] data;
  begin
    // Setup Phase：建立地址、数据与控制信号
    @(posedge PCLK);
    #1;
    PSEL    = 1'b1;
    PENABLE = 1'b0;
    PWRITE  = 1'b1;
    PADDR   = addr;
    PWDATA  = data;

    // Access Phase：拉高 PENABLE，进入写使能阶段
    @(posedge PCLK);
    #1;
    PENABLE = 1'b1;

    // 等待 PREADY 拉高（eReRAM 编程完成，最长约 10μs）
    while (!PREADY) begin
      @(posedge PCLK);
    end

    // 检查是否发生从机错误
    if (PSLVERR) begin
      $display("[ERROR] APB Write Error at addr=0x%03X", addr);
    end else begin
      $display("[INFO]  APB Write OK: addr=0x%03X, data=0x%08X", addr, data);
    end

    // 释放总线
    @(posedge PCLK);
    #1;
    PSEL    = 1'b0;
    PENABLE = 1'b0;
    PWRITE  = 1'b0;
  end
endtask
```

```verilog APB 读操作（Task）
// APB 读操作 Task —— 从 eReRAM 指定地址读取 32-bit 数据
task apb_read;
  input  [11:0] addr;
  output [31:0] rdata;
  begin
    // Setup Phase
    @(posedge PCLK);
    #1;
    PSEL    = 1'b1;
    PENABLE = 1'b0;
    PWRITE  = 1'b0;
    PADDR   = addr;

    // Access Phase
    @(posedge PCLK);
    #1;
    PENABLE = 1'b1;

    // 等待 PREADY（读操作通常在 1～2 个周期内完成）
    while (!PREADY) begin
      @(posedge PCLK);
    end

    // 采样读数据
    rdata = PRDATA;

    if (PSLVERR) begin
      $display("[ERROR] APB Read Error at addr=0x%03X", addr);
    end else begin
      $display("[INFO]  APB Read OK: addr=0x%03X, data=0x%08X", addr, rdata);
    end

    // 释放总线
    @(posedge PCLK);
    #1;
    PSEL    = 1'b0;
    PENABLE = 1'b0;
  end
endtask
```

```verilog 顶层仿真调用示例
// 顶层仿真：复位后执行写入与读回校验
initial begin
  // 初始化信号
  PCLK    = 0;
  PRESETn = 0;
  PSEL    = 0;
  PENABLE = 0;
  PWRITE  = 0;
  PADDR   = 0;
  PWDATA  = 0;

  // 保持复位 10 个时钟周期
  repeat(10) @(posedge PCLK);
  PRESETn = 1;
  repeat(5)  @(posedge PCLK);

  // 写操作：向地址 0x010 写入 0xDEAD_BEEF
  apb_write(12'h010, 32'hDEAD_BEEF);

  // 读回校验
  apb_read(12'h010, read_data);
  if (read_data !== 32'hDEAD_BEEF) begin
    $display("[FAIL] 数据不一致：期望 0xDEADBEEF，实际 0x%08X", read_data);
    $finish;
  end else begin
    $display("[PASS] 读写校验通过");
  end

  $finish;
end

// 时钟生成：100MHz
always #5 PCLK = ~PCLK;
```

</CodeGroup>

<Tip>
  在 Gate-Level Simulation 中建议启用 `+neg_tchk` 选项以检测负时序裕量（Negative Slack）违例，并加载昕原提供的 SDF 文件进行时序回标，确保仿真结果与 STA 签核结论一致。
</Tip>
