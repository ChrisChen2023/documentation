昕原半导体 eReRAM IP 是一款基于阻变存储（Resistive Switching）原理的嵌入式非易失性存储器 IP，专为需要低功耗、高可靠性存储的 SoC 及 MCU 设计场景而优化。相较于传统 Flash 与 OTP 存储方案，eReRAM 在写入速度、字节寻址灵活性、功耗及擦写寿命等关键维度均具备显著优势，可无缝集成至主流 CMOS 工艺节点，帮助设计团队在缩短上市周期的同时满足安全存储与配置管理需求。

## eReRAM 技术原理

eReRAM 利用金属氧化物薄膜中导电细丝（Conductive Filament）的可逆形成与断裂来表征逻辑"0"与"1"状态，无需高压擦除操作，存储单元结构简单，与标准 CMOS 工艺兼容，无需额外特殊掩模层。

### 对比传统存储技术优势

| 特性 | eReRAM | NOR Flash | OTP |
|------|--------|-----------|-----|
| 写入电压 | 低（内部生成） | 需要高压泵 | 需要高压泵 |
| 写入速度 | \< 10μs/字节 | 毫秒级 | 一次性 |
| 字节寻址 | 支持 | 不支持（块擦除） | 不支持 |
| 擦写寿命 | \> 100K 次 | \~10K–100K 次 | 仅 1 次 |
| 待机功耗 | 极低 | 中等 | 极低 |
| 工艺兼容性 | 标准 CMOS | 需特殊工艺 | 标准 CMOS |

<Tip>
eReRAM 支持字节级随机读写，无需整块擦除即可更新单字节数据，非常适合频繁更新的校准参数与配置寄存器场景。
</Tip>

## 产品核心特性

### 支持工艺节点

昕原半导体 eReRAM IP 已完成以下工艺节点的流片验证与交付：

- **28nm** CMOS（超低功耗版本）
- **40nm** CMOS
- **55nm** CMOS
- **130nm** CMOS（适用于汽车级及工业级高可靠性应用）

<Note>
如需其他工艺节点（如 22nm、16nm FD-SOI）支持，请联系昕原半导体获取定制化 NRE 报价。
</Note>

### 存储容量选项

eReRAM IP 提供从 4Kb 至 4Mb 的多档容量配置，可根据目标应用灵活选择：

**4Kb / 8Kb / 16Kb / 32Kb / 64Kb / 128Kb / 256Kb / 512Kb / 1Mb / 2Mb / 4Mb**

### 工作温度范围

| 等级 | 温度范围 | 适用场景 |
|------|----------|----------|
| 工业级 | -40°C 至 +85°C | 工业控制、IoT 终端、消费类 SoC |
| 汽车级（AEC-Q100） | -40°C 至 +125°C | 车身控制、ADAS、车载 MCU |

## 总线接口支持

eReRAM IP 原生支持以下 AMBA 总线协议，可直接挂载至主流 SoC 互联矩阵：

- **AMBA APB**（Advanced Peripheral Bus）：适用于低速配置寄存器访问
- **AMBA AHB**（Advanced High-performance Bus）：适用于高带宽代码/数据读取

总线数据位宽为 32-bit，地址位宽可配置为 8-bit 至 16-bit，具体范围取决于所选容量配置。

## 典型应用场景

eReRAM IP 广泛应用于以下 MCU / SoC 内嵌存储场景：

- **安全密钥存储**：存储设备唯一 ID、加密根密钥（Root Key）、证书指纹
- **校准数据**：模拟前端（AFE）校准系数、传感器偏移量、ADC 增益校正值
- **启动代码（Boot Code）**：小容量固件引导程序，支持安全启动（Secure Boot）
- **配置参数**：系统出厂配置、用户自定义参数、OTA 升级标志位
- **数据日志**：高温高可靠性场景下的故障事件记录（Fault Log）
