## 核心技术规格

### 工艺节点与电源电压

| 参数 | 规格值 |
|------|--------|
| 支持工艺节点 | 28nm / 40nm / 55nm / 130nm CMOS |
| 核心供电电压（VDD） | 1.8V（28nm / 40nm / 55nm）；3.3V（130nm） |
| 编程电压（VPROG） | 内部电荷泵自动生成，无需外部高压供电 |
| I/O 供电电压（VDDIO） | 1.8V 或 3.3V（与所选工艺节点匹配） |

<Note>
编程所需高压由 IP 内部电荷泵模块生成，芯片系统级无需提供额外编程电压轨，简化 PCB 电源设计。
</Note>

</Tip>

| 随机读取吞吐量 | — | 100 MHz | AHB 接口，单周期读 |

### 写操作

| 参数 | 典型值 | 最大值 | 条件 |
|------|--------|--------|------|
| 写入电流峰值（IWRITE） | 0.6mA | 1mA | 编程脉冲期间，内部电荷泵供电 |
| 字节写入延迟（tWRITE） | 5μs | 10μs | TT 工艺角，25°C |
| 页写入延迟（16 字节） | 80μs | 160μs | TT 工艺角，25°C |

<Note>
写操作期间建议通过总线协议的 PREADY / HREADY 信号检测写入完成状态，不应依赖固定等待周期数，以兼容不同工艺角的时序偏差。
</Note>

## ECC 支持

eReRAM IP 可选配内置 ECC（Error Correcting Code）模块，采用 SECDED（Single Error Correction, Double Error Detection）算法：

| 参数 | 规格值 |
|------|--------|
| ECC 算法 | Hamming SECDED |
| 保护粒度 | 每 32-bit 数据字独立 ECC |
| ECC 开销 | 7-bit 校验位 / 32-bit 数据字（约 22% 面积开销） |
| 错误中断 | 可配置单 bit 纠正中断 / 双 bit 检测中断（通过寄存器控制） |
| ECC 状态寄存器 | 提供错误地址、错误类型、错误计数寄存器 |

<Note>
ECC 模块为可选配置项。不使用 ECC 时，存储阵列面积和功耗均更优。汽车级及安全关键应用（如 ISO 26262 ASIL-B/D）建议启用 ECC。
</Note>
