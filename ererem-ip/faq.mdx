  <Accordion title="eReRAM 与 Flash、OTP 的区别是什么？" icon="microchip">
    eReRAM（嵌入式阻变存储器）、Flash 和 OTP 是三种不同原理的非易失性存储技术，各有其适用场景：

    **存储原理：**
    - **eReRAM**：通过施加电场改变金属氧化物薄膜（如 HfOx）的阻态（高阻/低阻）来存储数据，属于电阻型存储。
    - **Flash（NOR/NAND）**：利用浮栅（Floating Gate）或电荷陷阱（Charge Trap）捕获/释放电子来编程/擦除，属于电荷型存储。
    - **OTP（一次性可编程）**：通过不可逆的物理击穿或熔丝断裂完成编程，数据写入后永久固化，无法修改。

    **关键性能对比：**

    | 指标 | eReRAM（昕原） | NOR Flash | OTP |
    |---|---|---|---|
    | 编程电压 | 低（可与 VDD 兼容） | 需要高压 VPP（约 10V） | 需要高压（约 5–10V） |
    | 编程速度 | 纳秒至微秒级 | 微秒至毫秒级 | 微秒级（单次） |
    | 擦除单位 | 按 bit/word | 按扇区（最小 4KB） | 不可擦除 |
    | 可重复擦写次数 | 10⁵ ~ 10⁶ 次 | 10⁴ ~ 10⁵ 次 | 0（一次性） |
    | 工艺集成 | 与逻辑工艺兼容，无需特殊掩膜 | 需要专用 Flash 工艺 | 可与逻辑兼容 |
    | 待机功耗 | 极低 | 较低 | 极低 |

    **如何选择：**
    - 需要**多次擦写 + 低功耗 + 标准逻辑工艺**集成：选择 eReRAM。
    - 需要**大容量代码存储**且可接受专用工艺：选择 NOR Flash。
    - 需要**芯片 ID、密钥等一次性烧录**场景：选择 OTP。
  </Accordion>

  <Accordion title="IP 交付周期一般是多久？" icon="clock">
    IP 的交付周期取决于所选配置、工艺节点可用性以及授权类型：

    **标准授权（已量产节点）：**
    - NDA 签署完成后，**软件交付包（Verilog 模型、数据手册、仿真套件）**可在 **5–10 个工作日**内提供。
    - **完整 GDS/LEF 及时序库**视交付配置不同，通常需 **2–4 周**完成交付准备与授权审核。

    **定制化配置（新容量/位宽/工艺适配）：**
    - 如需对标准 IP 进行容量或接口定制，昕原将提供定制化报价与排期，通常 **4–12 周**。

    **新工艺节点开发：**
    - 全新工艺节点从评估到流片验证交付，通常需要 **6–12 个月**，具体取决于代工厂 PDK 成熟度。

    <Note>
    为加快交付流程，建议在正式下单前提前签署 NDA 并提交目标工艺节点、容量、接口宽度等需求规格。
    </Note>
  </Accordion>

  <Accordion title="eReRAM 的数据保持时间是多少？如何通过加速测试验证？" icon="shield-halved">
    **数据保持规格：**
    昕原 eReRAM IP 的数据保持时间（Data Retention）在额定工作条件下达到 **10 年（85°C 存储温度）**，满足以下工业标准：
    - JEDEC JESD47：半导体器件可靠性鉴定标准
    - AEC-Q100 Grade 1（-40°C ~ 125°C，适用于汽车级应用）

    **加速测试验证原理：**
    数据保持的加速测试基于 **Arrhenius 方程**，通过在高温下加速阻态退化来推算常温寿命：

    ```
    t_life = A × exp(Ea / k × T)
    ```

    其中：
    - `Ea`：激活能（eReRAM 典型值约 1.0–1.2 eV）
    - `k`：玻尔兹曼常数（8.617 × 10⁻⁵ eV/K）
    - `T`：测试温度（开尔文）

    **典型加速测试方案：**

    | 测试温度 | 加速因子（相对 85°C） | 验证等效寿命 | 测试时间 |
    |---|---|---|---|
    | 150°C | ~32× | 10 年 | ~2,700 小时 |
    | 175°C | ~200× | 10 年 | ~440 小时 |
    | 200°C | ~1,000× | 10 年 | ~88 小时 |

    **测试方法：**
    1. 将器件在目标温度下编程后放入高温炉（不加电）。
    2. 每隔固定时间取出样品，在室温下读取并检验数据完整性。
    3. 记录失效率，拟合 Arrhenius 曲线，外推至额定工作条件下的保持寿命。

    <Note>
    加速测试数据由昕原可靠性实验室完成，详细报告可在 NDA 条件下提供。客户无需自行开展保持测试，但可要求昕原提供原始测试数据。
    </Note>
  </Accordion>

  <Accordion title="编程电压 VPP 是否需要外部供给？" icon="bolt">
    这是 eReRAM 区别于传统 Flash 的重要优势之一。

    **昕原 eReRAM 的电压方案：**
    - **单电源工作（推荐方案）**：大多数昕原 eReRAM IP 配置支持使用核心电源 VDD（典型值 1.8V 或更低，视工艺节点而定）完成读取和编程操作，**无需外部高压 VPP**。
    - **双电源方案**：部分高容量或高性能配置提供独立的 VDDIO 引脚（通常 2.5V/3.3V）用于接口驱动，VPP 由片上电荷泵（Charge Pump）从 VDD 自动升压产生，对外部系统透明。

    **电荷泵集成说明：**
    - 标准交付的 eReRAM IP 已集成片上电荷泵，编程所需高压在芯片内部生成。
    - 电荷泵面积和功耗参数请参考目标节点对应的数据手册。

    <Warning>
    虽然无需外部 VPP，但在 PCB 设计时仍需确保 VDD 电源去耦充分（建议在电源引脚附近放置 100nF 和 10μF 去耦电容），以避免编程时的瞬态电流冲击导致电源噪声影响其他模块。
    </Warning>

    如需了解特定配置的电源要求，请参阅对应数据手册的"电气规格"章节，或联系昕原 FAE。
  </Accordion>

  <Accordion title="eReRAM 支持在线编程（In-System Programming）吗？" icon="code">
    **是的，eReRAM 完全支持在线编程（ISP，In-System Programming）。** 这是 eReRAM 相比 OTP 的核心优势之一。

    **ISP 能力说明：**
    - eReRAM 支持在系统正常运行期间，由主控制器（如 MCU、RISC-V 处理器）通过标准总线接口（AHB、APB、SPI 等）动态写入数据，无需掉电或进入特殊测试模式。
    - 支持**按字节（Byte）或按字（Word）**粒度的随机写入，无需像 NOR Flash 那样先擦除整块再编程。
    - **写入延迟**：单字写入延迟典型值为数百纳秒至数微秒，具体取决于工艺节点和 VDD 电压。

    **典型 ISP 应用场景：**
    - 固件 OTA（Over-The-Air）远程更新
    - 运行时参数/校准数据动态保存
    - 事件日志、计数器的实时写入
    - 芯片序列号、安全密钥的生产烧录

    **ISP 注意事项：**
    - 编程期间，如发生意外断电，当前正在写入的 word 数据可能丢失，但其余已写入数据不受影响。
    - 对安全关键数据（如密钥）建议采用"写-验证"（Write-and-Verify）策略，写入后立即回读确认。
    - 同地址连续写入时，需遵守 IP 规定的最小写入间隔（Tprog），避免超过耐久性限制。
  </Accordion>

  <Accordion title="时序库文件支持哪些格式（.lib/.db）和工具？" icon="wrench">
    昕原 eReRAM IP 的时序库文件覆盖业界主流格式，兼容主流 EDA 综合与签核工具：

    **交付的时序库格式：**

    | 文件格式 | 说明 | 典型用途 |
    |---|---|---|
    | `.lib`（Liberty ASCII） | 标准 Liberty 格式，包含时序弧、功耗、约束 | Synopsys DC、Cadence Genus 综合 |
    | `.db`（Liberty Binary） | Liberty 二进制编译版本 | Synopsys Design Compiler 加速读取 |
    | `.lef`（LEF） | 抽象物理层描述，包含引脚位置和面积 | Cadence Innovus、Synopsys ICC2 布局布线 |
    | `.gds` / `.gds2` | 全物理版图 | 流片 Tapeout |
    | `.cdl` | SPICE 网表 | LVS 验证（Calibre/PVS） |

    **工艺角（PVT Corner）覆盖：**
    - 典型角：TT / 1.8V / 25°C
    - 快角：FF / 1.98V / -40°C
    - 慢角：SS / 1.62V / 125°C
    - 低压慢角：SS / 1.62V / -40°C（适用于 SSTA 全角分析）

    **兼容的 EDA 工具：**

    | 工具类别 | 工具名称 |
    |---|---|
    | 逻辑综合 | Synopsys Design Compiler (DC)、Cadence Genus |
    | 物理实现 | Synopsys IC Compiler II (ICC2)、Cadence Innovus |
    | 静态时序分析 | Synopsys PrimeTime (PT)、Cadence Tempus |
    | 功耗分析 | Synopsys PrimePower、Cadence Voltus |
    | 物理验证（DRC/LVS） | Siemens Calibre、Synopsys PVS |

    <Note>
    `.lib` 和 `.db` 文件以工艺角为单位分别打包交付，命名规范为 `ererem_<capacity>_<corner>.lib`，例如 `ererem_4k32_ss_1p62v_125c.lib`。如需额外工艺角或 SSTA（统计静态时序分析）格式，请联系昕原提出定制需求。
    </Note>
